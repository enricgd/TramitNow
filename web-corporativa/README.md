# Web corporativa

Versión compilada de la web corporativa de TramitNow (un solo HTML), publicada en
https://web.henrik11.duckdns.org mientras no haya dominio propio.

Para publicar una versión nueva, sustituye `index.html` y ejecuta:

    sh infra/nas/deploy-web-corporativa.sh

También se puede publicar otro fichero directamente: `sh infra/nas/deploy-web-corporativa.sh ~/Downloads/web-corporativa-v5.html`.
